# Mini Shop: Premium E-commerce Platform

A luxurious, high-end e-commerce platform built with Python (Flask) with premium UI design.

## 🚀 How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/Noren11/Mini_Shop.git
cd Mini_Shop
```

### 2. Create a virtual environment
```bash
python -m venv venv
```

### 3. Activate the virtual environment
- **Windows:**
  ```bash
  .\venv\Scripts\activate
  ```
- **Mac/Linux:**
  ```bash
  source venv/bin/activate
  ```

### 4. Install requirements
```bash
pip install -r requirements.txt
```

### 5. Run the application
```bash
python app.py
```

### 6. View the Shop
Open your web browser and go to: **[http://127.0.0.1:5000](http://127.0.0.1:5000)**

*Note: The database (`site.db` or `sqlite.db`) will be automatically created on the first run.*
